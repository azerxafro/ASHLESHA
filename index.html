[ 02 // CAPSTONE ] • Final Year Major Project

Indigenous Integrated Railway Track Monitoring System (ITMS)

🏆 2nd Prize Winner - Core Category
(₹20,000 Award)
Project Abstract & Research Gap

Traditional railway track inspection relies on manual walking or expensive imported TRC vehicles. ITMS presents an indigenous, contactless multi-sensor edge platform built on an ARM SBC (Radxa Cubie A7A with 3-TOPS NPU) executing real-time Edge-AI defect classification alongside 6-axis IMU vibration monitoring, and GPS/LoRa geo-tagged alerting.
